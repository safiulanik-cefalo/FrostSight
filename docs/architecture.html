High-level architecture

Streaming path in the MVP Batch, reference and support Stretch scope or optional Scheduler

Why the collector sits outside. Free Edition limits outbound internet from notebooks and jobs, so everything that calls an external URL lives in one Python package that runs on GitHub Actions. On the AWS target the same code runs as a job task.

One pipeline, one serial job. Free Edition allows one active pipeline and five concurrent job tasks per account. Bronze, both silver flows, quarantine and the lookup share the ingest pipeline, and the orchestrate job runs its three tasks in order every 10 minutes.

Replay reuses the live path. Replay files land in the same folders. Silver reads them through a separate flow with its own watermark, and gold writes them only to the history table, never to current risk.
